# DigiAfriK VIRAL AI

**Imagine. Crée. Réalise.**

Application Android-first pour aider les créateurs francophones à concevoir, organiser et analyser leurs contenus courts.

## Stack
- Expo + React Native + TypeScript
- Expo Router
- Convex prévu pour le backend distant
- Android prioritaire

## État du prototype
- Tableau de bord créateur
- Générateur de hooks, scripts et hashtags par niche (modèles locaux)
- Bibliothèque de brouillons sauvegardée sur l'appareil
- Défi de progression sur 7 jours

## Lancer
`npm install`
`npx expo start`

## Backend
Le projet Convex de développement existe déjà dans le compte du propriétaire. La connexion et le déploiement des fonctions restent à réaliser avec le CLI Convex depuis un environnement de développement.

## Transparence
Les modèles de contenu actuels fonctionnent localement et ne sont pas un service IA génératif connecté. Les statistiques TikTok doivent être saisies par l'utilisateur ou obtenues via une intégration officielle autorisée. Aucune viralité n'est garantie.
